Acme Security

This page is deliberately long and is not expected to change during a demo. It is the control: whatever else happens, this page should report as unchanged on every run.

Data handling

Content is encrypted in transit and at rest. Each tenant is isolated at the storage layer, and no tenant key is shared between environments.

Access

Access is granted per workspace. Permissions are evaluated on every request rather than cached at session start, so a revocation takes effect immediately.

Crawling

Our crawler identifies itself and honours robots.txt. It reads a sitemap when one is published and otherwise fetches pages conditionally, so an unchanged page costs almost nothing to re-check.
