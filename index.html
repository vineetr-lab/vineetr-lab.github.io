Acme Docs — Home

Acme is a fictional product used to test knowledge-base website sync. This site exists so an engineer can edit a page and watch the change flow into a knowledge base.

Every page here carries enough prose that the extractor produces a stable block of text, which is what the content hash is computed over. Navigation and footer are stripped before hashing, so changing the menu will not register as a content change.
